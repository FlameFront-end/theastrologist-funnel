# Clean frontend

Поддерживаемая React-версия клиентской воронки The Astrologist без бэкенда.

```bash
npm install
npm run dev
```

Состояние теста сохраняется локально под версией ключа `theastrologist-quiz-state-v1`. Извлечённая копия в `../../work/extracted-site` используется только для визуального сравнения и не является исходным кодом оригинального приложения.
